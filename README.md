# 🧩 Resume Section Service (Dynamic Content Management)

The **Resume Section Service** manages the granular, modular components of a resume. It allows users to add, reorder, and customize different sections like *Experience*, *Education*, *Skills*, and *Projects* dynamically.

---

## 📌 Core Features

- **Dynamic Section Schema**: Uses a flexible JSON-based storage strategy to handle different types of content (list of items, paragraphs, skill tags) in a single unified table.
- **Drag-and-Drop Reordering**: Supports bulk reordering of sections to customize the visual hierarchy of the resume.
- **Visibility Control**: Toggle individual sections on or off without deleting the data.
- **AI Integration Support**: Tracks whether a section was manually written or generated by the AI Content Service.
- **Modular Architecture**: Each section is independent, allowing for infinite customization of the final resume document.

---

## ⚙️ Technical Specifications

- **Framework:** Spring Boot 3.x
- **Persistence:** Spring Data JPA + MySQL (using `LONGTEXT` for JSON content)
- **Port:** `8084`
- **Data Model:** Highly flexible `Map<String, Object>` content mapping.

---

## 🛣️ API Endpoints

| Method | Endpoint | Description |
|--------|----------|-------------|
| `POST` | `/api/sections` | Create a new dynamic resume section |
| `GET` | `/api/sections/resume/{id}` | Retrieve all sections for a specific resume (ordered) |
| `PUT` | `/api/sections/{id}` | Update the content or title of a section |
| `DELETE` | `/api/sections/{id}` | Permanently remove a section |
| `POST` | `/api/sections/reorder/{id}` | Update the display order of multiple sections |
| `PATCH` | `/api/sections/toggle/{id}` | Toggle the visibility of a section (Show/Hide) |
| `POST` | `/api/sections/bulk/{id}` | Perform bulk updates for multiple sections at once |

---

## 🚀 How to Run

1. **Pre-requisites:**
   - MySQL database with `resume_builder` schema.
   - **Service Registry** should be running.
2. **Setup:**
   - Copy `src/main/resources/application-local.properties` to `application.properties`.
   - Ensure your database connection settings are correct.
3. **Run:**
   ```bash
   mvn spring-boot:run
   ```

---

## 📂 Project Structure

- `SectionController.java`: Endpoints for dynamic section manipulation.
- `ResumeSection.java`: Core entity with UUID-based IDs and JSON content converter.
- `JsonConverter.java`: Utility to map Java Maps to MySQL JSON strings.
- `SectionType.java`: Enum defining supported modules (EXPERIENCE, EDUCATION, etc.).
